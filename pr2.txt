Stage 1 — Core Logic Infrastructure

Goal:

Create the minimal theorem-proving kernel.

Implements:

parser
term representation
unification
basic rewriting
proof objects
proof checker

Acceptance:

?- check_proof(Proof).
true.

Stage 2 — Recursive Program Analysis

Goal:

Understand recursive programs structurally.

Implements:

recurrence extraction
call graph generation
termination heuristics
example generation

Example:

sum(N,S)
→
sum(n)=sum(n-1)+n

Stage 3 — Gaussian Discovery Engine

Why multistage PRs are essential

Because each layer depends on verified lower layers.

For example:

Bad parser
→ bad recurrence extraction
→ bad matrix
→ false formula
→ invalid proof

So each PR should freeze correctness before the next abstraction layer.

Most important architectural rule

discover_conjecture \= prove_theorem.

Discovery and proof must remain separate stages.

That separation is what keeps the system mathematically honest.
